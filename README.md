# Сервис короткиз ссылок

## Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/vicon22/LinkShortenerApp
   cd LinkShortenerApp
   ```

2. Откройте проект в IDE

3. Выполните команду:
    ```
    maven clean package
    ```
4. Выполните команду:
    ```
    java -jar LinkShorterApp-0.0.1-SNAPSHOT.jar
    ```

## Использование

Для начала программа предоставляет меню авторизации с выбором действий:
1. Войти по UUID
2. Создать нового пользователя
3. Выйти

Для начала необходимо зарегистрироваться(Выберите пункт 2)

После программа предоставит основное меню:

1. Создать ссылку
2. Перейти по ссылке
3. Удалить ссылку
4. Изменить лимит переходов
5. Выйти из аккаунта
6. Завершить программу


Выберите необходимое вам действие и вводите необходимые данные.

---

## Примеры использования

### Создание короткой ссылки
1. Войдите в основное меню
2. Введите цифру 1 и введите оригинальную ссылку, срок действия и лимит использования. 
Программа создаст короткую ссылку и выведет её на экран.

### Переход по короткой ссылки
1. Войдите в основное меню
2. Введите цифру 2 и введите короткую ссылку. Программа переведет вас в браузер и откроет ссылку.
